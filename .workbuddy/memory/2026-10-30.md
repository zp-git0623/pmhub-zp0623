## 手工电表登记页面：分页区导出（公用组件）

- 背景：`pmhub-ui/src/views/monitor/manualElectricity/index.vue` 需要"导出全部 / 导出当前页"，导出按钮放在分页栏内，且后续新页面复用。
- 分页本身已具备：前端 `list?pageNum=1&pageSize=10` → 后端 `startPage()`（PageHelper）。`total=0` 时 `<pagination v-show="total > 0">` 隐藏，所以截图里看不到分页条。
- 后端：`ManualElectricityRecordController#export`（POST `/monitor/manualElectricity/export`，权限 `monitor:manualElectricity:export`）。传 `recordIds`（逗号分隔）→ 只导当前页；不传 → 按查询条件全量导出（不调 `startPage()`）。新增 `ManualElectricityExportVo`（`pmhub-system/.../domain/vo/`）承载 `@Excel` 列定义，避免污染实体和 `BaseEntity`（`ExcelUtil.getFields()` 会扫父类字段，只取带 `@Excel` 的）。
- 前端公用件：
  - `src/components/Pagination/index.vue` 增加 `extra` 具名插槽：有插槽时自行渲染「共 N 条」，并把 `total` 从 el-pagination 的 layout 中剔除，容器改 flex 右对齐（`.with-extra`）。
  - `src/components/ExportButton/index.vue`：props `url/params/rows/idField/idsParam/fileName/pageNum/total`，内部封装下拉 + `this.download`，已在 `main.js` 全局注册。
- 新页面接入模板：
  ```html
  <pagination v-show="total > 0" :total="total" :page.sync="queryParams.pageNum" :limit.sync="queryParams.pageSize" @pagination="getList">
    <export-button v-if="canExport" slot="extra" url="xxx/export" :params="exportParams" :rows="list" :total="total" :page-num="queryParams.pageNum" file-name="xxx" />

  ```
- SQL：`pmhub-boot/sql/monitor_manual_electricity.sql` 追加打印 + 导出两个权限菜单与授权（order_num 4=打印、5=导出），需在库里执行后导出才不 403。注意 `report_template.sql` 里原本就声明过 `monitor:manualElectricity:print`，两边都有 `NOT EXISTS` 保护，先跑哪个都不会重复插入。

### 排版修复：分页栏元素重叠

- 现象：导出按钮加进分页栏后「共 N 条 / 导出 / 页码」挤在一起、页码被裁切。
- 根因：`src/assets/styles/ruoyi.scss` 第 121-124 行 `.pagination-container .el-pagination { position: absolute; right: 0 }`，分页条脱离文档流盖在左侧内容上；且 `.pagination-container` 固定 `height: 25px`。
- 修复：`Pagination` 组件的 `.with-extra` 分支里给分页条重置 `position: static; right: auto; flex: 0 0 auto`，容器 `display:flex; justify-content:center; height:auto; min-height:32px`，整体居中一行。
- 验证方式（本机可复用）：手写最小 HTML 加载真实 `node_modules/element-ui/lib/theme-chalk/index.css`，把 ruoyi.scss 的覆盖规则和组件样式都写进去，构造 el-pagination 的真实 DOM 结构，用 Chrome headless `--screenshot` 出图对比修复前后，一次看清重叠/居中效果，不必启动整个 Vue 项目。
